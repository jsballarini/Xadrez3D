# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/),
and this project adheres to [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-07-28

### Added

- Monorepo com cliente, servidor e pacote shared
- Tabuleiro 3D jogável (React Three Fiber)
- Singleplayer vs Stockfish WASM com níveis 1–10
- Multiplayer com salas por código e nickname
- Chat escrito por sala
- Voz e webcam via WebRTC
- Ranking Elo persistido em JSON
- Relógios, espectadores e reconexão de sessão
- Motor de IA local (alpha-beta) com Stockfish opcional
